Reconnect backfill

Keep only the latest eligible message per device. This global setting applies immediately to new messages; existing records retain their expiry. Set 0 to disable and clear offline backfill. Online delivery continues.

Server diagnostics

Routing counters since the server process started; they reset on restart. Backfills count selected candidates, not confirmed clipboard writes.

When a device is not receiving

  1. Use a protocol-3 client and check its connection status.
  2. On Devices, check receive direction, pause, accepted report and data lease.
  3. For reconnects, check the backfill window and expiry. New devices receive no prior history.
  4. Check client filters and sensitive-content settings. Sensitive text may stay in the inbox without changing the system clipboard.

# RustClipSync Server 3.0.0

**Breaking compatibility:** requires client wire protocol **3** at `/api/...`.
Use Desktop **0.5.0**, Omaclipsync **0.4.0** and shared core **0.4.0**. Mobile
applications and Fcitx input methods are released separately; verify their
protocol support or retain server **v2.0.0** for older clients.

- Filter every device's metadata and body delivery by confirmed direction and
  pause state. Unknown, revoked and expired directions receive nothing.
- Fence direction control by device/session/version, with real WSS ACKs and
  authenticated HTTP fallback. Explicit logout revokes state; valid activity
  refreshes its 30-day inactivity expiry.
- Keep one eligible offline candidate per device with write-time expiry. Global
  reconnect backfill defaults to 5 minutes, range 0–1440; zero clears/disables
  offline replay without disabling live synchronization. Changes apply immediately
  and are audited; corrupt configuration safely falls back to zero.
- Add Devices / Accounts / Settings / About administration. Read-only device
  diagnostics show direction, pause, accepted/revoked/expired reports, activity,
  report source/version and data lease. Details help supports hover, keyboard
  focus and touch. Reading diagnostics does not refresh device TTL or cursors.
- Show server version and manual, credential-free GitHub update checks in About;
  never automatically replace containers. Keep accounts, token revocation,
  independent administrator authentication and CSRF/session protections.
- Preserve stored device identities and encrypted SQLCipher data. Stop and back
  up the complete data volume, key, credentials and old image before upgrading.
  Old-protocol data is not automatically broadcast or treated as protocol 3.

Docker images: `ghcr.io/infinifar/rustclipsync-server:v3.0.0`, `:3.0.0` and
`:latest`. Example Compose keeps `127.0.0.1:8090:8090`; terminate verified HTTPS
at the reverse proxy or tunnel. SQLCipher is at-rest protection, not end-to-end
encryption; the server can read synced text.

Validation includes 47 Rust tests, strict Clippy, isolated HTTPS Chromium admin
acceptance and shared-core interoperability via both real WSS and forced HTTP
fallback. Historical memory figures are an older baseline, not a new benchmark.
